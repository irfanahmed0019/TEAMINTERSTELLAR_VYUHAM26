BUILDMYLOGIC ↔ VS CODE

Build, run, prove.

Install the BuildMyLogic extension to receive the same learning task inside VS Code, run the correct local checks, submit your project folder, and get a BuildMyLogic Mentor review on the website.

Download the latest VSIX extension (v0.3.4)

Linux

Install from the terminal
code --install-extension buildmylogic-vscode-0.3.4.vsix

Or open VS Code → Extensions → ⋯ → Install from VSIX… and select the downloaded file.

Windows

PowerShell
code --install-extension .\buildmylogic-vscode-0.3.4.vsix

Or use the VS Code Extensions menu and choose Install from VSIX….

macOS

Terminal
code --install-extension ~/Downloads/buildmylogic-vscode-0.3.4.vsix

If the code command is unavailable, install it from the VS Code Command Palette: Shell Command: Install 'code' command in PATH.

Set up Python, Git and a C compiler

BuildMyLogic runs your code on your own computer, so it needs these tools. You do not have to find the commands yourself: open the BuildMyLogic sidebar in VS Code and use its Setup tab. It detects your operating system, checks what is already installed, shows the exact command for anything missing, and its Install packages button runs the command in a visible terminal only after you confirm it. Nothing changes your computer without your OK.

Windows
winget install -e --id Python.Python.3.12
winget install -e --id Git.Git

C missions also need a C compiler: install MSYS2 (winget install -e --id MSYS2.MSYS2), then run pacman -S --needed mingw-w64-ucrt-x86_64-gcc in its shell.

macOS
xcode-select --install
brew install python@3.12

Apple's command line tools provide Git and the clang C compiler. Python comes from Homebrew (brew.sh) or python.org.

Linux (Debian/Ubuntu)
sudo apt update && sudo apt install -y python3 python3-venv python3-pip git build-essential

Fedora: sudo dnf install -y python3 python3-pip git gcc · Arch: sudo pacman -S --needed python python-pip git base-devel

After installation

1. Start a sessionStart the task on BuildMyLogic and copy the generated Session ID.
2. ConnectOpen the BuildMyLogic icon in VS Code and paste only the Session ID.
3. Build and runComplete each checkpoint in order, then click Run Tests Locally.
4. SubmitClick Submit to BuildMyLogic to send the project files for review.
