Use BuildMyLogic in VS Code

VS Code is the app where you write code. This small add-on connects it to your BuildMyLogic practice. You only install it once on each computer.

Use a computer with VS Code installed. This does not install anything automatically or change your code.

STEP 1 OF 4

Update v0.3.14: install this version, reload VS Code, then sign into BuildMyLogic Sessions and choose Create pairing code. Type its one-use code into the BuildMyLogic panel in VS Code. Display Session IDs do not connect new installations. Pairing needs the website pairing service to be available. Saved learning history is kept.

Download the add-on

Save this file on your computer. You do not need to open or unzip it.

Download BuildMyLogic v0.3.14

File: buildmylogic-vscode-0.3.14.vsix
Usually saved in your Downloads folder.

No VS Code yet? Install it from the official VS Code website, then return here.

Install the file in VS Code

  1. Open VS Code on this computer.
  2. Click Extensions in its left sidebar (the four-blocks icon).
  3. At the top of that panel, click ⋯, then Install from VSIX...
  4. Choose buildmylogic-vscode-0.3.14.vsix from Downloads and confirm.

This is an install step inside VS Code, not on this webpage. Only continue after VS Code says the extension is installed.

Keep VS Code open

If VS Code shows Reload Now or Reload Window, click it. Otherwise, leave VS Code open.

The add-on runs inside VS Code. Closing that app disconnects it from the website.

You do not need a separate server or a command to start the connection.

Pair with a one-use code

  1. Open BuildMyLogic Sessions while signed in.
  2. Choose Create pairing code. If pairing is unavailable, stop and keep your progress. Do not retry a display Session ID.
  3. In VS Code, open the BuildMyLogic panel. Enter the eight-character pairing code and choose Pair session.
  4. The code expires after five minutes and can be used once. Keep it private. Never enter your account password here.

The pairing code does not need Open VS Code, a browser launcher or local-network permission. Opening a project folder and approving any project inspection remain separate actions in VS Code.

Go to Sessions

Prefer an installation command?

Keep the downloaded file in Downloads. Run the matching command in your computer's terminal. The code command must already be available. If it is not, use the menu steps above instead.

Windows - PowerShell

code --install-extension "$HOME\Downloads\buildmylogic-vscode-0.3.14.vsix"

macOS / Linux - Terminal

code --install-extension "$HOME/Downloads/buildmylogic-vscode-0.3.14.vsix"

If you saved the file elsewhere, use that actual path instead.

Python, Git or a C compiler is missing

After installing the add-on, open the BuildMyLogic panel in VS Code and select its Setup tab. It checks your computer, shows the commands for missing tools, and offers Install packages. It asks before running commands in a visible terminal.

Some installs require your computer's administrator approval. Windows and macOS installation commands have not been tested on those operating systems. Nothing here promises a one-click installation.

The website still says it cannot connect
  1. Keep VS Code open and check the extension is installed and enabled.
  2. If you just updated it, reload VS Code.
  3. Allow Chrome's local-network permission if it asks, then try the folder button again.

Installing the add-on and selecting a folder happen on your computer. This website cannot do those steps on your behalf.
